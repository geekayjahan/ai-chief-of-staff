# AI Chief of Staff — build a Claude plugin from plain words

A ~30-minute lightning lesson. You start with a plain-English spec and, one capability at a time, build a **Claude plugin** that acts as your chief of staff: take a voice dump, get a three-sentence **daily brief** and a **Friday wrap**, and keep a weekly task cap honest — connecting to the apps you already use **without handing over the keys**. No code.

Then you ship it two ways: **ported into Claude Desktop** as a plugin, and — for anyone without Claude Code or Claude Desktop — **published as a local app** (a plain folder any chat assistant can run).

Built for people juggling several projects at once: hustling toward a new job or their own thing, and especially neurodivergent operators who just want to talk at something and have it sort the priorities out.

---

## The arc (what the live build follows)

```
plain-English spec  →  build capabilities, one at a time  →  port to Claude Desktop  →  publish as a local app
   app/plugin-spec.md      capture · daily-brief ·             solo-project-manager.plugin    local-app/
                           friday-wrap · connect
```

1. **Spec** — [`app/plugin-spec.md`](app/plugin-spec.md): the whole thing in plain English.
2. **Build** — four skills added incrementally to `plugins/solo-project-manager/skills/`:
   - `capture` — file a voice/brain dump verbatim, no sorting.
   - `daily-brief` — route new captures, then re-orient in three sentences + today's one thing.
   - `friday-wrap` — score the week, roll unfinished work into the next under the cap, check goals.
   - `connect` — read from one app (calendar/tasks), read-only, least privilege.
3. **Port** — `./build-plugin.sh` packs the source into `solo-project-manager.plugin` → install in Claude Desktop.
4. **Publish** — [`local-app/`](local-app/) runs the same chief of staff in any LLM, no install.

## Install it — Claude Desktop plugin

1. Open `solo-project-manager.plugin`. Claude Desktop shows a preview; accept the install.
2. Pick a folder for your PM (a new or existing one — the setup skill creates it).
3. Say **"set up my project manager."** The `setup-pm` skill walks you through guided onboarding (you · your projects · goals · guardrails) and writes your personalised files.
4. Open that folder in a session and start: *"where am I?"*

## Run it locally — no Claude Code or Desktop

Grab `local-app/` (or `solo-chief-of-staff-local.zip`) and follow [`local-app/RUN-LOCALLY.md`](local-app/RUN-LOCALLY.md): onboard once by pasting `ONBOARDING.md` into any assistant, then each session paste `CLAUDE.md` and talk to it. Same behaviour, nothing installed.

## Session flow — how to run it

Once installed, a working session goes like this:

1. **Onboard once** — say **"set up my project manager."** Answer the phases (you · projects · goals · guardrails); it writes your personalised files. You only do this the first time.
2. **Open with** — **"where am I?"** → the three-sentence daily brief plus today's one thing.
3. **Dump anytime** — just talk at it. `capture` files the brain dump verbatim; the next brief routes it.
4. **Close the week** — say **"friday wrap."** It scores the week, rolls unfinished work forward under the cap, and checks it against your goals.
5. **Optional** — say **"connect my calendar"** (or tasks) for a read-only pull from one app.
