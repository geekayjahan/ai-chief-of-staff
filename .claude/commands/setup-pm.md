Read `.claude/skills/setup-pm/SKILL.md` and run the onboarding end to end.

Templates live in `templates/` at the root of this kit. Read them, substitute the
`{{PLACEHOLDER}}` markers with the user's answers, and write the personalised files into the
folder they choose.

Rules that hold for the whole run:

- Ask one phase at a time. Do not move on until the phase is answered.
- Never invent content. If the user skips something, write `→ fill when ready`.
- Ask where the files should go before writing anything. Never overwrite `templates/`.
- When every phase is answered, summarise what was written and where, then tell the user to
  open that folder in a fresh session.
