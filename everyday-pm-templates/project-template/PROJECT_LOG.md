## RULES

1. **Log time as it's spent.** Don't backfill at end of week. The data goes stale.
2. **If over cap:** Don't extend the cap. Cut next week's cap proportionally instead.
3. **Late-night work counts.** If you sat down for it, it counts.
4. **Strategic thinking counts.** If you're sitting and writing planning notes, log it. Walking-and-thinking doesn't.
5. **Master agent reads this Mondays.** It informs the weekly plan and pushes back if the project is creeping.
